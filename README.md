# README - Mateuszinho Aventura

## Sobre o Jogo
Mateuszinho Aventura é um jogo educativo desenvolvido especialmente para crianças com Processamento Auditivo Central (PAC), combinando estímulos visuais e auditivos para uma experiência de aprendizado divertida e eficaz.

## Módulos do Jogo
1. **Português**: Atividades de identificação de classes gramaticais e escrita de palavras
2. **Matemática**: Desafios de operações matemáticas básicas
3. **Desafio dos Sons**: Novo módulo de fonética com atividades de dígrafos, hiatos e encontros consonantais

## Instruções de Instalação

### Requisitos
- Navegador web moderno (Chrome, Firefox, Edge ou Safari)
- Não é necessário servidor web - o jogo funciona localmente

### Passos para Instalação
1. Extraia todos os arquivos deste pacote ZIP para uma pasta no seu computador
2. Mantenha a estrutura de pastas intacta
3. Abra o arquivo `index.html` no seu navegador

### Estrutura de Arquivos
- Arquivos HTML, JS e CSS na pasta raiz
- Arquivos JSON na pasta `data`
- Imagens na pasta `assets/images`
- Áudios na pasta `assets/audio`

## Usando suas Imagens
Para usar suas próprias imagens:
1. Copie suas imagens para a pasta `assets/images/fonetica`
2. Os nomes dos arquivos devem corresponder às palavras no jogo (ex: "chave.png", "rio.png")
3. Recarregue a página para ver suas imagens no jogo

## Solução de Problemas
Se encontrar erros de "arquivo não encontrado":
1. Verifique se todos os arquivos foram extraídos corretamente
2. Confirme que a estrutura de pastas está intacta
3. Certifique-se de que está abrindo o arquivo `index.html` diretamente do navegador
